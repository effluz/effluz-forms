# UI/UX specs

One file per surface. Each states: screens, flows, states, both-language copy
for fixed chrome, Laws of UX applied by name, accessibility notes.

| File | Surface | Users |
|---|---|---|
| `renderer.md` | Public form pages, progress, errors, confirmation screen, closed message, fixed email template parts | The public |
| `builder.md` | Draft editing, page and field editors, logic editor, translations side by side, live preview, publish validation, consent guidance | Staff |
| `manager.md` | Form list, lifecycle actions, settings, QR code, submission list and detail, export, dead jobs | Staff |
